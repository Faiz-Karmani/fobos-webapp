Tampilan

Kode adm4 = kode kelurahan/desa Kemendagri (format xx.xx.xx.xxxx). Kosongkan bila tidak dipakai.

Rekaman (Record) tersimpan di browser ini

Selama Record, browser menyimpan: posisi 10 Hz (CSV), IMU ringkasan 5 Hz (CSV), dan UBX RAWX 1 Hz + SFRBX. Salinan lengkap (RAWX penuh, IMU 200 Hz) selalu ada di kartu SD Fobos Mini, satu set file per nyala.

Putar ulang rekaman

Untuk demo di dalam ruangan (pameran) ketika RTK tidak bisa fix. Data diputar di peta seperti siaran langsung, lengkap dengan grafik getaran, penanda guncangan, dan ringkasan.

Dari file
  • .zip hasil "Unduh semua" dari web app (berisi posisi + IMU 5 Hz)
  • F####_pos.csv dari kartu SD, boleh bersama F####_imu.csv (getaran dihitung dari IMU 200 Hz)
  • _web_posisi.csv, atau .pos RTKLIB (hasil PPK, format lat/lon derajat)
  • .zip berisi file-file di atas (terkompresi atau tidak)
